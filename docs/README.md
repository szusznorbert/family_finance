# Dokumentáció

- [Jelenlegi architektúra](architecture.md) — a repository tényleges struktúrája, futtatási elemei, függőségei és ismert hiányai.
- [Projektagentek](../.codex/agents/README.md) — a projekt Codex agentjei és használatuk.
- [Branching stratégia](branching-strategy.md) — epic-task azonosítóhoz kötött branch-, commit- és PR-szabályok.
- A repository közös agent-skilljeinek leírása, szerepkörei és forrásai az [agent skill katalógusban](../.agents/skills/README.md), a forrás- és hash-nyilvántartás a [`skills-lock.json`](../skills-lock.json) fájlban található.

Architektúra-, adatbázis-, hitelesítési, telepítési vagy eszközverzió-változás után frissítsd az architektúra dokumentum megfelelő részét, és módosítsd benne az ellenőrzés dátumát.
